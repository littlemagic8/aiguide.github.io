# AI 工具全教程

国内用户一站式 AI 工具使用指南，覆盖 ChatGPT、Grok、Gemini、Claude、X 等。

在线访问：https://littlemagic8.github.io/aiguide.github.io/

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```
