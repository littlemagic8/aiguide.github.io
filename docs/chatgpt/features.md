## 功能总览

| 功能 | 说明 | 适用场景 |
| --- | --- | --- |
| 对话 | 多轮对话、追问、上下文记忆 | 日常问答、头脑风暴 |
| 文件分析 | 上传文档/表格/图片并提问 | 资料总结、数据解读 |
| 联网搜索 | 获取最新信息并引用来源 | 时效性问题 |
| 图像生成 | 文生图 | 插图、创意设计 |
| Canvas | 独立编辑区，协作写作与改代码 | 写作、编程 |
| Projects | 项目化组织对话与文件 | 长期任务管理 |
