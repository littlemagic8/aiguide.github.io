# ChatGPT 注册与账号完整教程

::: tip 更新说明
本文基于 2026 年最新流程整理，仅提供官方注册与账号管理建议。
:::

## 一、注册前准备

1. **邮箱**：推荐使用 Gmail、Outlook、iCloud 等海外邮箱。部分国内邮箱（尤其是 QQ、163）可能收不到验证码或被限制。
2. **网络环境**：需要能够正常访问 chatgpt.com 的网络。
3. **手机号**：注册过程中有时需要短信验证。国内手机号有时可用，但成功率不稳定，建议准备可接收国际短信的号码。
4. **密码管理**：建议使用密码管理器生成并保存强密码。

## 二、官方注册步骤

1. 打开官网：[https://chatgpt.com](https://chatgpt.com)
2. 点击右上角 **Sign up**
3. 选择注册方式：
   - 使用邮箱注册（推荐）
   - 或使用 Google / Apple / Microsoft 账号一键登录
4. 输入邮箱地址，点击继续
5. 查收验证邮件，点击验证链接
6. 设置密码（至少 8 位，建议包含大小写字母 + 数字 + 符号）
7. 按提示完成姓名填写
8. 如出现手机号验证，按要求输入并完成验证
9. 注册成功后自动登录

## 三、账号安全设置（强烈建议完成）

1. **开启两步验证（2FA）**
   - 登录后点击左下角头像 → Settings → Security
   - 开启 Multi-factor authentication
   - 推荐使用 Authenticator App（如 Google Authenticator、Microsoft Authenticator）

2. **检查登录设备**
   - 在 Security 页面查看近期登录设备和地点
   - 发现异常立即退出其他会话并修改密码

3. **绑定备用邮箱（如有）**
   - 增加账号找回成功率

## 四、常见注册问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 提示不支持该地区 | IP 所在地区受限 | 更换支持地区的网络后重试 |
| 收不到验证邮件 | 邮箱被拦截或延迟 | 检查垃圾箱，更换邮箱重试 |
| 手机号无法接收验证码 | 运营商限制或地区问题 | 更换号码或使用可接收国际短信的号码 |
| 注册后无法登录 | 网络或缓存问题 | 清除浏览器缓存，更换浏览器或设备 |

## 五、账号使用建议

- 尽量固定登录设备和网络环境，减少频繁切换
- 不要与他人共享账号
- 不要在不可信的第三方网站输入账号密码
- 重要对话建议导出备份
- 定期检查订阅状态和支付方式

::: warning 重要提醒
不推荐购买成品账号或共享账号。此类账号存在封号、隐私泄露、无法续费、对话被他人查看等风险。
:::

# ChatGPT 核心功能使用指南

本文系统介绍 ChatGPT 的主要功能与使用技巧，帮助你高效使用 Plus / Pro 权益。

## 一、基础对话功能

### 1. 模型选择
登录后可在对话界面选择不同模型（具体可用模型取决于你的订阅档位）：

- 快速响应模型：适合日常问答、翻译、简单写作
- 高级推理模型（如 GPT-5.6 Sol / Sol Pro）：适合复杂分析、编程、数学、科研

**使用建议**：
- 简单任务用快速模型，节省额度
- 复杂任务再切换到高级推理模型

### 2. 对话技巧
- 提供清晰的背景和目标
- 分步骤提问，而不是一次抛出过多要求

路径：左下角头像 → Customize ChatGPT

可设置：
- 你希望 ChatGPT 如何称呼你
- 你的职业、常用场景
- 希望它默认采用的回答风格（简洁 / 详细 / 专业等）

设置后，几乎所有新对话都会自动带上这些偏好。

- 文档：PDF、Word、TXT、Markdown

- 总结长文档 / 论文 / 报告
- 提取关键信息与数据

- 代码审查与解释
- 对比多份文件差异

### 使用技巧
1. 上传前尽量清理无关内容，减少干扰
2. 明确告诉它你要什么结果（总结、提取、对比、翻译等）

**注意事项**：
- 联网结果仍需人工核实关键信息

## 四、图像生成与编辑

### 主要能力
- 根据文字描述生成图片

好的提示词通常包含：
- 主体（什么东西）

- 构图与视角
- 色彩与光影
- 用途（海报、头像、封面等）

- 可以实时看到完整文档

## 六、Projects（项目）

- 长期进行的研究或写作项目

**使用技巧**：

1. **按任务选模型**：简单任务用快速模型，复杂任务用推理模型
2. **善用自定义指令**：减少每次重复说明背景

5. **注意额度消耗**：图片生成、Deep Research、长上下文、Codex 消耗较大

## 一、API 与 ChatGPT 网页版的区别

| 项目           | ChatGPT 网页 / App      | OpenAI API                  |
|----------------|-------------------------|-----------------------------|
| 使用方式       | 图形界面对话            | 代码调用                    |
| 计费方式       | 月费订阅                | 按 Token 用量计费           |
| 是否共享额度   | 否                      | 否，完全独立                |
| 适合人群       | 普通用户                | 开发者、产品、自动化场景    |
| 是否需要编程   | 不需要                  | 通常需要                    |

## 二、申请 API Key

1. 打开 [https://platform.openai.com](https://platform.openai.com)
2. 使用你的 OpenAI 账号登录
3. 进入 **API keys** 页面
4. 点击 **Create new secret key**
5. 给 Key 起一个名字，创建后立即复制保存

::: warning 安全提醒
- API Key 只显示一次，请妥善保存
- 不要把 Key 提交到公开代码仓库
- 不要在前端代码中暴露 Key
- 建议为不同项目创建不同的 Key，并设置用量限制
:::

## 三、充值 API 额度

1. 进入 platform.openai.com 的 Billing 页面
2. 添加支付方式（通常需要支持的信用卡）
3. 设置月度预算或手动充值
4. 建议开启用量告警，防止意外超支

## 四、基础调用示例

### Python 示例（官方库）

```bash
pip install openai
```

```python
from openai import OpenAI

client = OpenAI(api_key="你的API_KEY")

response = client.chat.completions.create(
    model="gpt-4o-mini",   # 根据实际可用模型调整
    messages=[
        {"role": "system", "content": "你是一个有帮助的助手。"},
        {"role": "user", "content": "用一句话介绍人工智能。"}
    ]
)

print(response.choices[0].message.content)
```

### 使用 curl 测试

```bash
curl https://api.openai.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## 五、常用参数说明

| 参数              | 说明                                   | 建议 |
|-------------------|----------------------------------------|------|
| model             | 使用的模型                             | 根据任务选择 |
| messages          | 对话历史                               | 必填 |
| temperature       | 随机性（0~2）                          | 严谨任务用低值，创意任务用高值 |
| max_tokens        | 最大生成长度                           | 控制成本 |
| top_p             | 核采样                                 | 一般与 temperature 二选一调节 |
| stream            | 是否流式输出                           | 需要实时显示时开启 |

## 六、成本控制建议

1. **优先使用性价比高的模型**完成简单任务
2. 设置 `max_tokens`，避免生成过长无用内容
3. 在平台设置月度预算和告警
4. 对用户输入做长度限制，防止恶意消耗
5. 缓存常见问题的回答，减少重复调用
6. 开发阶段使用较低成本的模型进行调试

## 七、常见错误与处理

| 错误信息                        | 可能原因                     | 处理方法 |
|---------------------------------|------------------------------|----------|
| Invalid API Key                 | Key 错误或已删除             | 检查并重新生成 |
| Insufficient quota              | 余额不足                     | 去 Billing 充值 |
| Rate limit exceeded             | 请求频率过高                 | 降低频率或升级限额 |
| Model not found                 | 模型名称错误或无权限         | 检查模型名称与权限 |
| Timeout / Connection error      | 网络问题                     | 检查网络与代理设置 |

## 八、安全与最佳实践

- 永远不要把 API Key 写死在前端代码中
- 使用环境变量或密钥管理服务存储 Key
- 为 Key 设置权限和 IP 限制（如平台支持）
- 定期轮换 Key
- 监控异常调用量
- 对用户输入做过滤，防止 Prompt 注入
